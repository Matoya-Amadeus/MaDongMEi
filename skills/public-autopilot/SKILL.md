# public-autopilot

Use this skill when you need the public MaDongMei flow that recalls, classifies, captures, and promotes a note in one pass.

## Scope

- Route stable facts and decisions into `knowledge/wiki/`.
- Route reusable procedures into `skills/public-autopilot/published/`.
- Keep output public, portable, and free of private paths.

## Canonical commands

- `./memoryctl autopilot`
- `./bootstrap.sh`
- `./install_selfcheck.sh`
- `./install_validation_matrix.sh`
- `./quality_gate.sh`

- `./memoryctl pre-hook --query "<request>"`
- `python3 scripts/madongmei_doctor.py --json`
