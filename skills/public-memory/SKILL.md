# public-memory

Use this skill when you need to work with the open MaDongMei memory surface.

## Scope

- Capture public notes.
- Search and recall public notes.
- Export and import JSONL.
- Review weekly summaries.
- Keep the surface free of private paths, secrets, and device-local state.

## Canonical commands

- `./bootstrap.sh`
- `./install_selfcheck.sh`
- `./install_validation_matrix.sh`
- `./quality_gate.sh`
- `./memoryctl capture`
- `./memoryctl search`
- `./memoryctl recall`
- `./memoryctl review`
- `./memoryctl weekly-review`
- `./memoryctl export-jsonl`
- `./memoryctl import-jsonl`

- `./memoryctl pre-hook --query "<request>"`
- `python3 scripts/madongmei_doctor.py --json`
